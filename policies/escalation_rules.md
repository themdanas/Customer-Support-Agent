# Escalation Rules

## Refund Threshold Escalation

Any refund request exceeding $75, or exceeding 80% of the order's total
value, must be escalated to a human agent for approval before the refund is
processed. This threshold applies regardless of the reason for the refund.

## Repeat Contact Escalation

If a customer has contacted support more than twice about the same order
without resolution, escalate to a human agent even if the individual issue
would otherwise be auto-resolvable. Repeated unresolved contact is itself a
signal that something about the case needs human judgment.

## Angry or Frustrated Customers

If a customer's message expresses strong frustration, anger, or a threat to
leave a negative review or cancel their account, escalate to a human agent
regardless of whether the underlying request would otherwise be
auto-approvable. Do not attempt to de-escalate through automated responses
alone.

## Policy Ambiguity

If a customer's situation does not clearly match any documented policy, or
matches multiple policies with conflicting guidance, escalate to a human
agent rather than guessing. Do not fabricate a policy that does not exist in
the retrieved documents.

## Lost Package Claims

All lost package claims (see Shipping Policy) must be escalated to a human
agent for carrier investigation rather than automatically refunded.

## Non-Refundable Item Disputes

If a customer disputes the non-refundable classification of an item (for
example, arguing a "final sale" item was mislabeled), escalate to a human
agent rather than overriding the policy automatically.
